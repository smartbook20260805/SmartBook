# 📘 SmartBook

SmartBook 是一套使用 HTML、CSS、JavaScript 開發的個人記帳系統。

---

## 🚀 目前功能

### 💰 收支管理
- 收入
- 支出
- 分類
- 備註

### 🧾 代墊管理
- 代墊人
- 已收回 / 未收回
- 收回日期

### 📊 Dashboard
- 收入
- 支出
- 餘額
- 未收回代墊

### 📈 報表
- 月報表
- 分類統計
- 圓餅圖
- 長條圖

### 📄 匯出
- Excel
- PDF（開發中）

### 🔍 搜尋
- 關鍵字
- 類型
- 分類
- 日期

### 📱 PWA
- 手機安裝
- Service Worker

---

## 🛠 開發工具

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- Chart.js
- jsPDF
- Git
