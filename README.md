# 📘 SmartBook

一套使用 HTML、CSS、JavaScript 開發的個人記帳系統。

## 功能

- ✅ 收支記帳
- ✅ 收入 / 支出分類
- ✅ 代墊管理
- ✅ 已收回 / 未收回
- ✅ Dashboard
- ✅ 最近交易
- ✅ 每人未收回代墊
- ✅ 搜尋與篩選
- ✅ 圓餅圖
- ✅ 長條圖
- ✅ Excel 匯出
- ✅ PWA
- ✅ Git 版本控制

## 開發工具

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- Chart.js
- SheetJS
- jsPDF（開發中）
